# Funkgerät: Stimmen

`funk-stimmen.wav` enthält die Stimmen für das Funkgerät unten links (`assets/js/radio.js`). Alle Abschnitte sind
echte Sprachaufnahmen von Lingua Libre auf Wikimedia Commons und stehen unter CC0 1.0 (gemeinfrei,
https://creativecommons.org/publicdomain/zero/1.0/). Eine Namensnennung ist nicht nötig, die Quellen stehen trotzdem
hier. Lizenz und Datei wurden am 18.11.2026 über die Commons-API geprüft. Es ist keine Computerstimme dabei.

Bearbeitung: Stille vorn und hinten abgeschnitten, Lautstärke angeglichen, auf 8 kHz mono und 8 Bit gebracht und
hintereinander in eine Datei gelegt. Die Liste `VOICE_CLIPS` in `radio.js` nennt Start und Länge jedes Abschnitts.
Erst beim Abspielen setzt `radio.js` daraus Funksprüche zusammen: Bruchstücke mit Rauschen dazwischen, schmales
Funkband, Übersteuerung, Knacken, Aussetzer, Schwund und Wörter, die mitten im Wort abreißen. Die beiden Sätze laufen
nur stark gedämpft, sodass man lediglich hört, dass jemand spricht.
